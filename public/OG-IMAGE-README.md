# Open Graph Image Setup

## What you need to do:

1. **Create an OG Image** (1200x630px recommended)
   - Use Canva, Figma, or any design tool
   - Include:
     - Your name: "Berkat Bate'e"
     - Title: "Full Stack Developer & AI Enthusiast"
     - Background: Dark theme matching your portfolio
     - Logo/Photo (optional)
     - Visual elements from your portfolio design

2. **Save as `og-image.png`** in this `public/` folder

3. **Example content ideas:**
   - Your hero section background
   - Animated logo screenshot
   - Code editor theme
   - Tech stack icons (React, Python, etc.)

## Recommended dimensions:
- **Facebook/LinkedIn:** 1200 x 630px
- **Twitter:** 1200 x 600px (or use same as above)

## Tools to create OG images:
- [Canva](https://www.canva.com/) - Easy drag & drop
- [Figma](https://www.figma.com/) - Professional design
- [Bannerbear](https://www.bannerbear.com/tools/open-graph-image-generator/) - OG generator
- [Og Image Playground](https://og-playground.vercel.app/) - Code-based
