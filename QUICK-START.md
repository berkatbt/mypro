### 3️⃣ Replace CV File (5-30 minutes)

**Quick Option (5 min):**
Use Canva CV template:
1. Go to [Canva Resume Templates](https://www.canva.com/templates/?query=resume)
2. Choose dark theme template
3. Fill in your info
4. Download as PDF
5. Save as `public/cv.pdf`

**Professional Option (30 min):**
Use Google Docs or Word, include:
- Header: Name, title, contact
- Summary/About
- Work Experience
- Education
- Technical Skills
- Projects (top 5 with links)
- Certifications

---

### 4️⃣ Create OG Image (10 minutes)

**Easy way with Canva:**
1. Go to [Canva](https://www.canva.com)
2. Create design → Custom size → 1200 x 630 px
3. Use dark background (#050505)
4. Add text:
   - Your name (large, white)
   - "Full Stack Developer & AI Enthusiast"
   - "Portfolio" or "berkatbt.github.io"
5. Add tech icons (React, Python, etc.)
6. Download as PNG
7. Save as `public/og-image.png`

**Or screenshot method:**
1. Open your portfolio
2. Screenshot the Hero section
3. Resize to 1200x630px
4. Save as `public/og-image.png`

## ❓ Troubleshooting

**Social links not showing?**
→ Make sure you updated `profile.js` with valid URLs

**CV not downloading?**
→ Check `public/cv.pdf` exists

**Scroll bar not showing?**
→ Try scrolling down, appears after scroll starts

**Console message not showing?**
→ Press F12, click "Console" tab, refresh page
